# 1.7 Event Tracking

## Added

- Added local SQLite telemetry for business CLI commands.
- Added `odoo-graph telemetry init` to initialize the telemetry database.
- Added `odoo-graph telemetry report` to run post-processing and analysis in one command.
- Report now covers session call counts, command frequency, follow-up, retry, expansion, path fan-out, batch model / field exploration, load overhead, and 30s / 60s / 120s gap sensitivity.

## Notes

- Telemetry is local-only and defaults to `~/.cache/odoo-graph/telemetry.sqlite3`.
- Use `ODOO_GRAPH_TELEMETRY_DB` to override the DB path.
- Use `--no-telemetry` for one invocation or `ODOO_GRAPH_TELEMETRY=0` to disable collection.
- `--help`, `--version`, root action, and shell-level startup failures are not part of the formal telemetry statistics.
