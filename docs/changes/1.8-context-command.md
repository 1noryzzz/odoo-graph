# 1.8.0 Context Command

## What changed

- Added `odoo-graph context <model> [<model> ...]` for seed-first model exploration.
- Single-model mode summarizes the seed model and suggests directly relevant inheritance, delegation, and relation models to inspect next.
- Multi-model mode focuses on the relationships inside an explicit model set.
- Both `human` and `json` output include `suggested_context_models`; seed mode may include a follow-up command.

## How to use it

```bash
odoo-graph context child.record --db odoo_demo
odoo-graph context child.record res.partner --db odoo_demo -f json
```

## Compatibility notes

The command reads existing dump files and does not require a dump schema change. Existing query commands keep their output formats.

## Intentionally excluded

This release does not add a persistent daemon or MCP transport; repeated calls still load the local dump per invocation.
